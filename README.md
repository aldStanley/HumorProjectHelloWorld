# Humor Project — Hello World

Week 1 assignment: a simple Next.js Hello World app.

## Run locally

```bash
cd humor-hello-world
npm ci
npm run dev
```

Open http://localhost:3000.

## Check

```bash
npm run lint
npm run build
```

## Deploy on Vercel

Import this GitHub repository, choose Next.js, and set the Root Directory to
`humor-hello-world`. Use the default build and installation settings.
After deployment is Ready, disable Deployment Protection and verify the unique
deployment URL in an Incognito window. Submit that deployment-specific URL for
Week 1, rather than the project alias that changes with future deployments.
